# Changelog

## 1.0.0

- Initial release.
- Folder and selection lookup for Explorer windows and the desktop.
- Shell-first lookup with UI Automation recovery and Windows 11 tab support.
- Direct native Desktop icon-list access for reliable selection lookup.
- Independent folder and selection statuses, sources, and diagnostics.
- Message-box demo, core tests, opt-in Explorer/Desktop tests, and Windows CI.
